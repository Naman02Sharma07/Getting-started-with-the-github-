# Simple Interest Calculator

This project provides a small Bash script to calculate **simple interest**.

## Formula

Simple interest is calculated as:

`SI = (P × T × R) / 100`

Where:
- `P` = Principal amount
- `T` = Time period (years)
- `R` = Annual rate of interest

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh <principal> <time> <rate>
```

Example:

```bash
./simple-interest.sh 1000 2 5
```

Output:

```text
Simple Interest = 100
```
